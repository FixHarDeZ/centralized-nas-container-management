# Gameplay / footage clip pipeline (preset `gameplay`, 0 credits, no Flow)

## Voiceover rule — no countdown or dates (Fix 2026-11-07)
- ห้ามพูดหรือขึ้นจอนับถอยหลัง/จำนวนวันถึงวันวางขาย (เช่น "อีก 118 วัน", ป้าย D-N) และห้ามวันที่ในเสียงพากย์ เพราะคลิปอาจถูกดูหลายเดือนหลังทำ แล้ววันจะผิด — ใช้ hook แบบไม่มีวันที่แทน (`gph-1/3/4/5/6/8/9` ไม่ใช่ `gph-2`/`gph-10`). ไม่ต้องใส่ release_date/release_pill ใน plan.json

## When to use
- Fix orders a clip แบบฟุตเทจ / gameplay / "ตัดฟุตเตจเกม" / "ฟุตเทจ" — any game product where real footage sells better than a generated presenter. Duration is per order (20 s typical).
- **ถ้าหาฟุตเทจเกมเพลย์จริงไม่ได้ (ไม่มี gameplay trailer / มีแต่คนพากย์ / ช่วงสะอาดไม่พอ) ให้ใช้ cinematic cutscene หรือ trailer ทางการมาทำได้เลย — ฟิกสั่งไว้ 2026-11-07: «ถ้าหาคลิปเกมเพลแล้วไม่มี หา cinematic cutscene หรือ trailer มาทำได้เลย»** → ไม่ต้องถาม ไม่ต้องย่อคลิปให้สั้นลงเพราะ "ไม่ใช่เกมเพลย์"; เกณฑ์ที่ยังบังคับเหมือนเดิมคือช่วงต้องไร้เสียงพูด + ไร้ตัวหนังสือ/โลโก้ (รอย Watermark/credit ที่ครอปออกได้ = ครอป ไม่ใช่เหตุผลปฏิเสธ) แล้วบอกฟิกใน delivery ว่าฟุตเทจเป็นแนว cinematic/trailer ไม่ใช่เกมเพลย์จริง
- This is mode 🎮 of `shopee-clip` (the router asked the mode question and ran intake). **House rules live in `/opt/data/skills/shopee-clip/references/house-rules.md`.** Quick recap: ห้ามราคา/สกุลเงิน/ส่วนลด ทั้งพูดและบนจอ (วันที่ pre-order/วางขายพูดได้ — ไม่ใช่ราคา), on-screen caption = EN ล้วน ≤2 คำต่อ beat, ไม่มีชื่อร้าน/watermark, soft CTA เฉพาะช็อตสุดท้าย (`Link below!`), hashtags gate ≤150 chars + zero CJK + ไม่มีแท็กราคา, deliver ผ่าน `/opt/data/skills/shopee-clip/scripts/send_clip.py` + hashtags block + basket-link block (ลิงก์ที่ฟิกส่งมา ส่งกลับ verbatim) — **บล็อก hashtags กับบล็อกลิงก์ แยกกันคนละ fenced code block เสมอ** **+ ส่งปุ่ม copy ด้วย `/opt/data/skills/shopee-clip/scripts/send_copy_buttons.py "<hashtags>" "<link>"` ทุกครั้งหลังส่งคลิป** (Telegram ไม่มีปุ่ม copy ให้ลิงก์ใน code block — ปุ่ม inline `copy_text` คือแบบที่ฟิกเลือก).
- **Multi-scene review gate ไม่บังคับ** (ไม่มี scene ไหนถูก gen ใน Flow) — ส่งครั้งเดียวพร้อม frame-check verdict.
- **0 เครดิต / ไม่ต้องเปิด Chrome / ไม่ต้องแตะ Flow เลย** ทั้งคลิปคือ yt-dlp + ffmpeg + TTS + PIL
- **ฟิกแนบคลิปอ้างอิง (ref) มาด้วย = เสียงคลิปเราต้องประมาณคลิปนั้น** → วัดเทียบ F0/ย่านความถี่/ความดัง/ดนตรีใต้พากย์ก่อนจูน แล้วส่ง 2 โทนเสียงให้ฟิกฟังเลือกในรอบเดียว: `references/audio-reference-matching.md`; สคริปต์วัด: `scripts/measure_audio.py`
- **NAS RAM น้อย (~4.5 GB ว่าง, swap เต็ม): งานหนัก (whisper, build, gates) รันทีละงานเท่านั้น** — subagent ขนานหลายตัวที่รัน whisper/build พร้อมกันทำ OOM จน Hermes gateway ตาย (ลูกตายเงียบ ไม่ส่งผลกลับ) → ถ้าลูกเงียบหาย ให้ตรวจไฟล์บนดิสก์เองแล้วทำต่อทีละงาน

## Game-cover sticker + cover image — DEFAULT on every gameplay clip (Fix 2026-11-07: "อยากให้ graphic ของคลิปทำ gameplay ให้มี crop หน้าปกเกมมาแปะในคลิปให้ด้วย ไม่บังจอแบบเดียวกับ presenter")
- **After build_v5 + master + remux**, add the game case cover as a cut-out sticker with `/opt/data/skills/shopee-clip/scripts/graphics_layer.py out.mp4 gfx.json final.mp4`. Plan:
  `{"image_stickers":[{"image":"cover_crop.jpg","x":520,"y":990,"h":220,"rot":-6,"start":<after cold open>,"end":<before hero / loop tail>,"w_est":165}],"avoid":[{"name":"footage","rect":[0,280,720,690]}]}`.
  - It goes BELOW the Thai subs (subs y≈707–830), clear of the footage window, the right-rail icons (x≥640) and the bottom-left caption.
  - **`w_est` ต้องคำนวณจากสัดส่วนปกจริง (`w = h × w0/h0` จากขนาด crop) แล้วบังคับ `x + w ≤ 640`** — ค่าตัวอย่าง x520/h220/w165 ใช้ได้เฉพาะปกเกือบสี่เหลี่ยม; ปกสูงแคบ (433×726 → h220 = w131) วาง x520 จะเลยขอบขวา x640 เข้าไอคอนขวาของแอป
  - Never put it on full-bleed hero / cold-open shots. **The sticker is one `image_stickers` entry per span BETWEEN hero segs** (e.g. one entry 2.2→8.9 s and another 11.1→14.6 s when a hero seg sits at 9–11 s) — a single start/end that spans a hero shows the sticker over full-bleed picture.
  - Re-run verify-clip after (graphics_layer re-encodes FB-safe + a −4 dB limiter).
- **cover_crop.jpg** = the CASE FRONT cropped tight out of Fix's ad image. **Get the bbox from a labelled grid, not from a free-eye estimate:** draw 50-px grid lines with PIL over the image, read the edges off the labels, then crop INSIDE the case edge. Free-eye estimates were 10–20 px off and let a corner badge (中文 彩盒) into the crop. Then vision-check the crop for: corner badges at the top-right of the art, a clipped title letter (widen the crop, don't accept it), and a red case-border strip (harmless, but name it). No price, QR or shop logo, and not the neighbouring case. When the ad has none, use the publisher's box art. Upscale the crop 2× (LANCZOS) before use so the sticker and thumbnail aren't soft.
  - **The sticker must show the WHOLE case front — never a partial crop.** When a promo panel/banner covers part of the case in the ad, cropping the clean region yields half a cover, and Fix rejects it. Gate by aspect ratio before use: a Switch/Switch 2 case front is ~1.6 h:w (368×599 measured); a crop near 1.0 or below (e.g. 440×387) means the case was cut. Then get a full cover: publisher/Nintendo store box art, or ask Fix once for a clean cover image (he supplies one quickly). Do not ship a half cover "for now".
  - Tested on the Yu-Gi-Oh clip: `ygo_cover_sticker_demo.mp4` (sent to Fix, msg 7137), cover at x433–605 / y836–1083, nothing covered.
- **Thumbnail:** run `/opt/data/skills/shopee-clip/scripts/make_cover.py` (pre-sub source, EN title ≤3 words), then `send_photo.py`. **Fix 2026-11-08: the thumbnail MUST also carry a crop of the product / game cover** (product clip → product crop; gameplay clip → game case cover crop from the listing image, same bbox rule as the sticker). make_cover alone is not enough: composite the cover crop onto the thumbnail (white border, bottom-right inside the safe zone) before sending. Fix's words: "ภาพหน้าปกที่ทำให้ ถ้าเป็นคลิปสินค้าแปะรูปสินค้าที่ crop ให้ด้วย และ gameplay ก็แปะรูปปกเกมให้ด้วย".

## Short clip (≤15 s, one or two clean windows) — direct ffmpeg, not build_v5
- Use `references/short-clip-ffmpeg.md` + `templates/short_clip_build.py` when build_v5's plan is overkill. Same gates (ffprobe, output flags, volumedetect on the OUTPUT, frame check, send_clip).
- Mixing traps that silently produce bad audio: a filter label used twice (split it with `asplit`); `amix duration=first` truncates; sidechain output follows the music input length (pad it); a silent source window leaves the clip VO-only.

## Steps
-1. **Multi-image intake first (Fix 2026-11-09):** `uv run --with pillow python /opt/data/skills/shopee-clip/scripts/intake_images.py <order_image> <workdir>` → one `vision_analyze` on `intake_sheet.jpg` covering every image Fix sent together (cover art, edition, listing title, platform badges) BEFORE footage search or plan. Later image messages for the same game = part of the order, never a new clarify.
0. Work dir `/opt/data/cache/scratch/<slug>/` — `cp <skill_dir>/fonts/*.ttf .` (Itim-Regular, Fredoka-SemiBold, FredokaSB-Static, Mali-Bold) ห้ามใช้ DejaVu/Liberation กับไทย (ไม่มีสระ → กล่องว่าง). **Fredoka-SemiBold.ttf เป็น variable font: drawtext (`fontfile=`) ใช้ได้ แต่ libass/ASS เลือกจาก fontsdir ไม่ได้ แล้ว fallback เป็น DejaVu เงียบ ๆ** → ใน ASS style ทุกตัวใช้ `Fontname=FredokaSB, Bold=0` (ไฟล์ static `FredokaSB-Static.ttf`) และยืนยันด้วย `ffmpeg -v verbose … -vf ass=… -f null - 2>&1 | grep fontselect`
1. **Hook + ข้อมูลเกม**: hook เลือกด้วย `python3 /opt/data/skills/shopee-clip/scripts/perf.py pick-hook --category game --prefix gph-` (ids `gph-1..10` ใน `/opt/data/skills/shopee-clip/templates/hooks.md`; ไม่ใส่ `--prefix` ได้ `game-N` ผิดชุด; ไม่มีข้อมูล perf = LRU). `web_search "<เกม> <platform> release date"` 1 ครั้ง → แนวเกม + จุดขาย + วันวางขาย. **ลิสติ้งที่ฟิกส่งมาอาจล้าสมัย**: ถ้าข่าวทางการใหม่กว่าเลื่อนวัน → ห้ามวันเก่าบนจอ/เสียง ใช้ PRE-ORDER หรือไม่แสดงวัน และบอกฟิกใน delivery ให้แก้ลิสติ้ง (ลิสติ้งที่ค้างวันเดิมทำให้คนซื้อเข้าใจผิด). **วันที่สองแหล่งขัดกัน** (หน้าร้าน ≠ search): ใช้ระดับเดือนเท่านั้นทั้งเสียงและจอ — ห้ามเลขวันหลุด แล้วบอกทั้งสองวันพร้อมเหตุผลใน delivery; ตรงกันถึงระดับวัน → ใช้ระดับวันได้ (hook 📅 ใช้ได้เฉพาะกรณีนี้; `pick-hook` ที่ได้ hook นับถอยหลัง/📅 ทั้งที่วันยังไม่ยืนยันจากผู้จัดจำหน่าย → ข้ามไปเลือก hook ที่ไม่มีวันที่ แล้ว log `hook_id: "custom-<slug>-N"` ตามที่คลิปก่อนหน้าทำ)
2. ฟุตเตจ: `uv tool run yt-dlp -f "bv*[height<=1080]+ba" --merge-output-format mp4 -o trailer.mp4 <YouTube official trailer>`; **ถ้าขึ้น `Sign in to confirm your age` ใช้ `--extractor-args 'youtube:player_client=tv_embedded'`** (ไม่ต้องคุกกี้); เลือกฟุตเตจด้วย contact sheet + ASR ตาม `references/footage-sourcing.md` (**จัดอันดับแหล่งด้วยผลรวมช่วงว่างที่วัดจาก ASR ก่อน ไม่ใช่ความยาว — สั้นพูดเยอะ/ยาวเงียบ เป็นแค่ค่าเฉลี่ย: preview 17 นาทีที่มีคนบรรยายตลอดใช้ได้จริง ~11 วิ แต่คลิป 2.5 นาทีเสียงขะยะมีช่วงว่าง ~28 วิ; cinematic ≠ gameplay**); Steam/Epic CDN mp4 `curl` ตรงๆ ได้; ลิงก์ Shopee Video → WAF กัน → ใช้ trailer ทางการแทนแล้วบอกฟิก. **ทันทีที่ได้ trailer ดึงซับอัตโนมัติมาทำตารางเสียง**: `uv tool run yt-dlp --write-auto-subs --sub-lang en --skip-download -o subs <url>` (ได้ `subs.en.vtt`; ห้ามใช้เทมเพลต `%(ext)s` — eval ของ shell ชนวงเล็บ) แล้ว parse เป็นรายการช่วง "มีคนบรรยาย":
   - ดึง body ต้องกินทั้งบรรทัด header (timestamp + `align:start position:0%`) ไม่งั้น `align/start/position` หลุดเข้า text แล้ว cue เปล่าทุกใบนับเป็นเสียงพูด → ช่วงว่างหายทั้งไฟล์
   - cue ที่มี tag `<c>` = word timestamp ใน tag คือ ground truth; auto-subs ซ้อน cue (repeat ข้อความก่อน) → strip tag + merge/dedupe ก่อนหา gap
   - cue มีแต่ `[music]` = ช่วงว่าง, มี `>>` = เสียงพูด. เพลงที่มีเนื้อร้องตลอดแต่ไม่มี `>>` = เพลง ให้ duck จัดการ ใช้ได้ทุกช่วง. cue เดียว `[music]` คลุมทั้งเรื่อง = ไม่มีเสียงพูด เลือกได้ทุกช่วง
   - **ทุก seg ต้องอยู่ในช่วงว่าง** (อังกฤษใต้พากย์ไทย = สองภาษาทับกัน ข้อห้ามแรก; การ์ดท้ายที่ประกาศชื่อเกมเป็นข้อยกเว้นเดียว เพราะ VO จบก่อนแล้ว). เว้นขอบ ≥0.1 วิ จากเสียงพูด
   - **อย่าเชื่อ gap จาก VTT ล้วนกับ trailer ยาว/reveal**: auto-subs มักไม่มี cue ช่วงต้นหรือช่วงบทในเกม (เห็นเป็นช่วงว่างหลายสิบวิทั้งที่มีบทพูด) → ยืนยันด้วย ASR (faster-whisper small, `vad_filter=False`) บนเสียงช่วงที่จะใช้ แล้วเขียน speech VTT จาก ASR ให้ build_v5 ใช้เป็น `vtt`. วิธีเต็มใน `references/footage-sourcing.md`
   - trailer บางเรื่องไม่มี auto-subs → เช็ค `--list-subs` ก่อนโหลด; **ซับโหลดติด `HTTP 429` = rate limit ของ YouTube → retry ครั้งเดียวแล้วพอ ข้ามไป ASR ตรง ๆ** (ASR คือ ground truth อยู่แล้ว); มีหลายตัว → โหลดเฉพาะซับทุกตัว (`--skip-download`) นับช่วงว่าง ≥1.5 วิ แล้วเลือกตัวที่ช่วงว่างพอ plan คลิป
   - ผลรวม seg ≥ DUR; **ใช้ trailer เรื่องเดียวทั้งคลิป** (คนละเรื่อง = เพลงกระโดดที่ seam); จำเป็นจริงใช้เรื่องที่สองเฉพาะเซกท้ายแล้วบอกใน delivery
3. **Encode MASTER ก่อนตัดเสมอ** (trailer มักเป็น AV1 1080p60): `ffmpeg -i trailer.mp4 -vf "scale=720:-2,pad=720:1280:0:320:black,fps=30,format=yuv420p" -c:v libx264 -preset veryfast -crf 20 -c:a aac -b:a 128k -ar 48000 -ac 2 master.mp4` (เก็บ trailer.mp4 ไว้ — hero shot ของ v5 crop จากต้นฉบับ). **Corner overlays are removed in THIS encode, not in the hero:** if the contact sheet shows a publisher/hardware FPS, DLSS or RTX panel in a corner, crop it out before scale (e.g. `crop=1560:878:0:100` on a 1920×1080 source whose overlay starts at x≈1605 top-right and x≈1674 bottom-right; 16:9 kept). The hero's centre 608-px crop is usually clear of corner overlays — verify on a frame, don't assume.

## Pitfalls (ทุกข้อแลกด้วยรันจริง)
- **Multi-title announcement trailers (Nintendo Direct / Switch 2 bundle reveals) are unusable as footage:** they cut to the other titles' logos and cinematics. Pick a single-title gameplay trailer for the product itself (search the publisher's channel, e.g. 'Gameplay Trailer' per game). Measured 2026-11-08 on RE:2 Z: F1Xpv60_yKQ had 0 gameplay frames in 130 s.
- **Trailer age gate (2026-11-08):** `Sign in to confirm your age` บล็อกทุก player_client ของ yt-dlp (tv_embedded/android/ios/mweb/web_creator) → ห้ามเสียเวลาไล่ client; หา trailer ทางการอีกตัว (ค้นด้วย web_search ชื่อเกม + "trailer") แล้วโหลดหลายตัวพร้อมกันเพื่อเทียบ
- **ASR (faster-whisper) หลอนบนเพลง/end-card** เช่น "The End" / "XBOX SOUND" ซ้ำทุก 2 วิ แล้ว build speech.vtt ที่ merge ทั้งช่วงเป็น speech → window ถูกปฏิเสธทั้งหมด. ตรวจ ASR JSON ด้วยตา/auto-subs แล้วเขียน `subs.en.vtt` มือ (speech = เฉพาะช่วงที่มีบทจริง) ก่อนรัน build
- **ซับต้นทางค้างในช่วงต้น window:** trailer บางเรื่องเผาซับจีน/อังกฤษค้างหลังเสียงบรรยายจบ 0.5–1 วิ → ตรวจ bottom strip (crop ล่าง 300px ที่เฟรมจริง ทุก 0.6 วิ) ที่จุดเริ่ม window ทุกครั้ง แล้วเลื่อน in ให้พ้น; หลังเลื่อนตรวจต่ออีกหน้าต่างที่จะใช้ (ช่วง end ก็อาจมีซับเริ่มใหม่)
- **VO สั้นกว่าเดดไลน์ (vo_end < DUR−3):** เพิ่มประโยคใหม่ + gap_after 0.30–0.40 แล้ว gen ใหม่ (เสีย 1 request) — ปรับ gap อย่างเดียวด้วย --from-take ไม่พอ ถ้าขาดเกิน ~1.5 วิ

- **เลือก trailer จากวินาทีที่เป็นเกมเพลย์จริงและไม่มีเสียงพูด ไม่ใช่จากความยาวหรือป้ายชื่อ**: trailer เรื่องเล่าที่บรรยายตลอดได้ช่วงใช้งานประมาณ 21 วิ; trailer ประกาศอีกเรื่องมีช่วง speech-free ยาวแต่เป็น cinematic เกือบทั้งหมดจนเหลือเกมเพลย์แค่ ~9 วิ — ทำ ASR + contact sheet ทั้งสองไฟล์ก่อนเลือก อย่าอ่านช่วงว่างจาก ASR อย่างเดียว
- **ช่วงเสียงอังกฤษใน trailer ที่มีบทพูดในเกม** VTT ของ auto-subs อาจไม่มีบทในเกม: ยืนยันด้วย `scripts/asr_speech_spans.py` ก่อนเชื่อ gap ทุกครั้ง
- **Work dir ต้องมีไฟล์ครบก่อน build**: `build_v5.py` resolve path ของทุกคีย์ใน plan เทียบกับโฟลเดอร์ plan.json — ต้องมี `fonts/` (โฟลเดอร์ ไม่ใช่แค่ .ttf ที่ราก), `subs.en.vtt`, `master.mp4`, `trailer.mp4`, `bg.png`, `vo.mp3`. ขาดไฟล์ใดไฟล์หนึ่งพังที่ขั้นตรวจก่อน render (FileNotFoundError) — ตรวจว่าครบก่อนรัน `--check`.
- **Rebase เมื่อ master encode จาก `-ss S`**: ทำ VTT ด้วย `scripts/rebase_vtt.py speech.vtt S subs.en.vtt`. **แต่ถ้า source ≤ ~20 นาที ให้ encode เต็มไฟล์ตาม step 3 (ไม่ใส่ `-ss`) ดีกว่า** — เสียเวลา encode แค่ไม่กี่นาที แล้ว master / trailer / speech.vtt / seg / audio ใช้ไทม์ไลน์เดียวกันทั้งหมด ไม่ต้อง rebase เลย; ใช้ window encode เฉพาะไฟล์ยาว (20+ นาที) ที่ encode เต็มไฟล์แพงจริง. seg แบบ `master` ใช้ `in` = เวลาจริง − S; seg แบบ `trailer` (hero) ใช้ `in` = เวลาจริงใน trailer แต่ต้องใส่ `audio_src: "master"` และ `audio_in` = เวลาจริง − S ไม่งั้นเสียงของ hero ถูกดึงจากเวลาผิด.
- **ซับ: ต้องเขียน `\\N` ใน plan.json (ได้ `\N` ในไฟล์)**: `gen_vo_natural.py` ใส่ข้อความ `sub` ลง ASS ตรงตัว. ถ้าเขียน `\\n` ไฟล์จะได้ `\n` ตัวเล็ก — libass ถือเป็น soft break และ sub_linecheck นับ `want=1` แล้ว FAIL ทั้งที่ตั้งใจสองบรรทัด. ตรวจก่อน build: `grep -c '\\N' subs.ass` ต้องตรงกับจำนวน event ที่ตั้งใจแบ่งบรรทัด.
- **ฟิต VO เข้าเดดไลน์ DUR−1.5** (เดดไลน์เทียบกับ *ซับ* ไม่ใช่เสียงพูด ซับจบหลังเสียงประมาณ 0.1 วิ): ตั้งเป้าให้วลีสุดท้ายจบ ≤ DUR−1.6. ลำดับปรับ ทุกรอบรัน `--from-take` (0 request): (1) `lead` 0.05; (2) `tempo` 1.07→1.08 (เกิน 1.08 ฟังรีบ); (3) gap_after ทุกช่อง ≥0.28 — ค่า 0.25 พอดีไม่นับเป็น gap >0.25 แล้ว GATE WARN; (4) ค่อยตัดคำ. มี `--check` ที่บรรทัด `VO end` ถ้าขึ้น LATE ทั้งที่ speech end ≤ เดดไลน์ ให้ดูว่าซับจบเกินหรือไม่.
- **Never `source` /opt/data/.env in the shell to get an API key.** A command that sources the secrets file gets held for approval, times out, and stalls the whole clip run. The VO script reads `GEMINI_API_KEY` from `/opt/data/.env` itself, so run `gen_vo_natural.py` with no env prefix. If a command is blocked for approval, stop and ask Fix once; do not rephrase it to reach the same outcome.
- **`terminal(workdir=…)` must be an existing directory.** A nonexistent workdir returns exit 126 with a stale `cd` error, the same symptom as the persisted-cwd trap. Set `workdir=/opt/data` (or any existing dir) and do the `mkdir` inside the command.
- **Source trailers over ~20 minutes: encode only the window you use.** A 31-minute gameplay upload is about 300 MB at 1080p. Cut the window with `-ss S -t D` at 1080p (`trailer_cut.mp4`), then build the 720x1280 master from that cut. Keep the cut as `trailer` and the master on the same timeline (t=0 = S), so no rebase is needed.
- **Printed icon, QR or price inside the cover art bbox.** Vision bounding boxes for a game cover can include a QR, a shopping-bag icon or an orange mark printed on or beside the artwork; these then show up in the sticker and the thumbnail. Cut the crop above the lowest printed element, re-crop, and vision-check the new crop before using it.
- **ASR (faster-whisper small, TH/EN) พลาดบทในเกม (2026-11-09 RE3 Switch 2 run):** window ที่ ASR บอกว่าเงียบ 432–453 s มี subtitle บทพูดจริง "What the fuck!?" ที่ 447–448 s และ "Jill! Over here!" ที่ 453. → ก่อนล็อก seg ต้องทำ bottom-strip subtitle montage (footage-sourcing §5b) ทุกช่วง แล้วตัดก่อนบทแรกที่เห็นในภาพด้วย margin ≥0.5 s ไม่ใช่เชื่อ ASR อย่างเดียว
- **Trailer ทางการ Switch 2 หลายเรื่องเป็นการ์ด/cinematic ล้วน** (launch trailer RE2/3/4 = multi-title, RE3 Z Version trailer = cinematic + card, age-gated). ตรวจด้วย contact sheet ก่อนเลือก. ถ้าไม่มี gameplay ทางการ → ใช้ gameplay capture ของ creator แต่ **ต้องแจ้งฟิกเรื่องลิขสิทธิ์ก่อนส่ง** (ใช้จริงแล้ว และฟิกเป็นคนตัดสินว่าโพสต์ได้ไหม)
- **Hook `gph-10` / `gph-2` = นับถอยหลังหรือวันวางขาย → เลี่ยง** แม้ LRU เลือกมาให้; ใช้ hook custom แล้ว log `hook_id: "custom-<slug>-N"` ตามที่คลิปก่อนหน้าทำ.
- **Walking/fire footage มักเงียบมาก (mean −35…−40 dB ต่อ seg)**: เลือกช่วงที่ดังกว่าในช่องว่างเดียวกัน (วัด `volumedetect` ทุกช่วงก่อน build) ถ้าไม่มีให้บอกใน delivery ว่า VO-led.
- **Shell `( cmd & )` ใน terminal foreground ถูกปฏิเสธ**: ส่งงานเรนเดอร์/ASR เป็น `terminal(background=true)` แล้ว poll ไฟล์ output ในคำสั่ง foreground สั้นๆ ไม่ใช่ sleep ยาว.
- **`verify-clip.py` ไม่มี arg = เลือกไฟล์ใหม่สุดใน Downloads ซึ่งอาจเป็นไฟล์ชื่อซ้ำจากงานเก่า (เช่น `final.mp4`)** → ตั้งชื่อคลิปเฉพาะงานก่อน copy เข้า Downloads แล้วส่ง path เต็มเข้า verify-clip ทุกครั้ง และดู `duration_s` ใน verdict ให้ตรงเป้า.
- **Combat trailers: ASR บอกเงียบทั้งที่มีเสียงคราง/กรี๊ดของตัวละคร ("Uh ah!", "Huh.")** — auto-subs VTT จับได้แต่ whisper ไม่จับ และ ASR รอบใหม่บนไฟล์เดียวกันอาจคืนช่วง speech ต่างจากรอบก่อน → ใช้ union ของ VTT + ASR ทุกรอบ, วาง seg ให้จบก่อนเสียงแรก ≥3 วิ, ยืนยันด้วย bottom-strip ซับ. `build_v5 --check` บน speech.vtt ใหม่คือตัวตัดสิน — ถ้ามันปฏิเสธ seg ให้ย้ายช่วง ไม่ใช่แก้ VTT ให้ผ่าน.
- **จูน `music_gain` ด้วย `duck_gate.py --gain <x>` ก่อน rebuild** — มันวัด delta จาก master + vo โดยไม่ต้อง render ใหม่ ลองค่า (0.75 → 0.5) จนผ่าน ≥6 dB แล้วค่อย build ครั้งเดียว.
