# Game-cover / product sticker + thumbnail (gameplay-clips)

Moved verbatim from SKILL.md on 2026-11-12. SKILL.md keeps the summary; the measurements and traps are here.

## Game-cover sticker + cover image — DEFAULT on every gameplay clip (Fix 2026-11-07: "อยากให้ graphic ของคลิปทำ gameplay ให้มี crop หน้าปกเกมมาแปะในคลิปให้ด้วย ไม่บังจอแบบเดียวกับ presenter")
- **After build_v5 + master + remux**, add the game case cover as a cut-out sticker with `/opt/data/skills/shopee-clip/scripts/graphics_layer.py out.mp4 gfx.json final.mp4`. Plan:
  `{"image_stickers":[{"image":"cover_crop.jpg","x":520,"y":990,"h":220,"rot":-6,"start":<after cold open>,"end":<before hero / loop tail>,"w_est":165}],"avoid":[{"name":"footage","rect":[0,280,720,690]}]}`.
  - It goes BELOW the Thai subs (subs y≈707–830), clear of the footage window, the right-rail icons (x≥640) and the bottom-left caption.
  - **`w_est` ต้องคำนวณจากสัดส่วนปกจริง (`w = h × w0/h0` จากขนาด crop) แล้วบังคับ `x + w ≤ 640`** — ค่าตัวอย่าง x520/h220/w165 ใช้ได้เฉพาะปกเกือบสี่เหลี่ยม; ปกสูงแคบ (433×726 → h220 = w131) วาง x520 จะเลยขอบขวา x640 เข้าไอคอนขวาของแอป
  - Never put it on full-bleed hero / cold-open shots. **The sticker is one `image_stickers` entry per span BETWEEN hero segs** (e.g. one entry 2.2→8.9 s and another 11.1→14.6 s when a hero seg sits at 9–11 s) — a single start/end that spans a hero shows the sticker over full-bleed picture.
  - **The borrowed end card is full-bleed too**: end the span at that seg's `t0` (printed by `build_v5 --check`), never at `DUR − loop_tail` — the end card carries the real logos, the copyright line and the CTA sub.
  - Re-run verify-clip after (graphics_layer re-encodes FB-safe + a −4 dB limiter). **It also re-encodes the audio through `alimiter=limit=0.5`**, so the `max < −3 dB` gate must be re-measured on `final.mp4` — verify-clip checks duration/profile only, not the peak.
  - **ยืนยันว่า sticker ขึ้นจริงด้วย pixel diff ไม่ใช่ vision**: เทียบเฟรมเวลาเดียวกันของ `out.mp4` (ก่อน graphics) กับ `final.mp4` (หลัง) — วัด 3 ค่า: inside-rect ช่วง sticker ขึ้น (ต้องสูง ~15–45), นอก-rect, และ rect เดียวกันแต่นอก-เวลา (sticker ยังไม่เริ่ม/จบแล้ว). สองค่าหลังเป็น baseline ของ re-encode noise — ต้องใกล้กันและ**ห้ามตัดสินด้วยค่าสัมบูรณ์ 0–2** (ขึ้นกับคอนเทนต์ บางคลิปได้ 3–5); baseline สองตัวที่ตรงกันยืนยันพร้อมกันทั้ง "ขึ้นแน่นอน" และ "ไม่ล้นไปโผล่นอก span"; vision อ่านเฟรมหลัง graphics คืนคำตอบที่ไม่น่าเชื่อถือ
- **cover_crop.jpg** = the CASE FRONT cropped tight out of Fix's ad image. Check completeness by aspect: a full case front is ~1.6 h:w; a crop noticeably shorter than that has clipped the case edge. Get the bbox from the gridded image via vision, then confirm the aspect before use. **Get the bbox from a labelled grid, not from a free-eye estimate:** draw 50-px grid lines with PIL over the image, read the edges off the labels, then crop INSIDE the case edge. Free-eye estimates were 10–20 px off and let a corner badge (中文 彩盒) into the crop. Then vision-check the crop for: corner badges at the top-right of the art, a clipped title letter (widen the crop, don't accept it), and a red case-border strip (harmless, but name it). No price, QR or shop logo, and not the neighbouring case. When the ad has none, use the publisher's box art — **source it from the game's own official site, not from retailers**: grep the site HTML for `package|box|product` image paths (the Muramasa site exposed `…/top_product_package-nsw2-standard.png`, 494×800 RGBA, h:w 1.62 = a full case front with alpha). Amazon / BestBuy / GameStop / MobyGames / GameFAQs / play-asia all block a plain `curl` — don't spend turns there. **Verify the download by OCR, not by a vision description**: vision read a correctly-downloaded cover as a completely different game title, so run RapidOCR on the PNG to confirm which title/region it is, and crop out any QR code and regional rating/language badges the official package art carries (they fail the "no QR" rule even on publisher art). Upscale the crop 2× (LANCZOS) before use so the sticker and thumbnail aren't soft.
  - **The sticker must show the WHOLE case front — never a partial crop.** When a promo panel/banner covers part of the case in the ad, cropping the clean region yields half a cover, and Fix rejects it. Gate by aspect ratio before use: a Switch/Switch 2 case front is ~1.6 h:w (368×599 measured); a crop near 1.0 or below (e.g. 440×387) means the case was cut. Then get a full cover: publisher/Nintendo store box art, or ask Fix once for a clean cover image (he supplies one quickly). Do not ship a half cover "for now".
  - Tested on the Yu-Gi-Oh clip: `ygo_cover_sticker_demo.mp4` (sent to Fix, msg 7137), cover at x433–605 / y836–1083, nothing covered.
- **Thumbnail:** run `uv run --with pillow --with numpy python /opt/data/skills/shopee-clip/scripts/make_cover.py` (pre-sub source, EN title ≤3 words; numpy is required, pillow-only fails), then `send_photo.py`. Pick `--t` from a moment after the last burned-in caption has ended, and read the `main_box` the script prints: place the cover composite outside that box (below it, bottom-right, x = W − w − 90, y = H − h − 250 — the sizing rule below derives h so this clears `main_box.bottom`) so it neither hides the title nor the caption; a thumbnail whose cover overlaps the title or a caption fails vision check. **Fix 2026-11-08: the thumbnail MUST also carry a crop of the product / game cover** (product clip → product crop; gameplay clip → game case cover crop from the listing image, same bbox rule as the sticker). make_cover alone is not enough: composite the cover crop onto the thumbnail (white border, bottom-right inside the safe zone) before sending. **ตั้งขนาดตามขอบที่ชนจริง — สอง constraint พร้อมกัน: `w ≤ ~620 px` (canvas 1080) ไม่ให้ล้นขอบซ้าย และ `y = H − h − 250 ≥ main_box.bottom` ไม่ให้ทับ title.** crop สินค้าสัดส่วน ~1.9:1 (แนวกว้าง) โดน constraint ความกว้าง → ตั้ง `w ≤ 620` แล้วคูณสัดส่วน (ตั้ง `h=520` จะกว้าง ~980 px แล้วล้นขอบซ้ายออกนอกเฟรม); **ปกเกม/กล่องสินค้าแนวตั้ง (h:w ~1.6) โดน constraint ความสูง** → คำนวณ `h` จาก `y = H − h − 250 ≥ main_box.bottom` ก่อน (canvas 1920, title ล่างที่ 1009 → h ≤ 661) แล้วค่อย `w = h × w0/h0` — ตั้งจากความกว้างกับปกสูง = การ์ดยาวขึ้นไปทับ title ทันที. วาง `x = W − w − 90`, `y = H − h − 250` แล้ว vision เช็คว่าไม่ชนข้อความปก. **เช็ค `main WxH` ที่ make_cover พิมพ์ด้วย**: `main` กว้างกว่า ~1000 px บน canvas 1080 = โดนตัดแม้ `--text` จะ ≤3 คำ (`MURAMASA REVENANT BLADES` ล้นจริง) → สั้นเหลือคำเดียว (เช่น `MURAMASA`). Fix's words: "ภาพหน้าปกที่ทำให้ ถ้าเป็นคลิปสินค้าแปะรูปสินค้าที่ crop ให้ด้วย และ gameplay ก็แปะรูปปกเกมให้ด้วย".
