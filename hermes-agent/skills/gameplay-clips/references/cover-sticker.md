# Game-cover / product sticker + thumbnail (gameplay-clips)

Moved verbatim from SKILL.md on 2026-11-12. SKILL.md keeps the summary; the measurements and traps are here.

## Game-cover sticker + cover image — DEFAULT on every gameplay clip (Fix 2026-11-07: "อยากให้ graphic ของคลิปทำ gameplay ให้มี crop หน้าปกเกมมาแปะในคลิปให้ด้วย ไม่บังจอแบบเดียวกับ presenter")
- **After build_v5 + master + remux**, add the game case cover as a cut-out sticker with `/opt/data/skills/shopee-clip/scripts/graphics_layer.py out.mp4 gfx.json final.mp4` (gameplay mode has no `post_presenter` report → run it WITHOUT `--report`, which belongs to the 🧑/📦 pipelines). Plan:
  `{"image_stickers":[{"image":"cover_crop.jpg","x":520,"y":990,"h":220,"rot":-6,"start":<after cold open>,"end":<before hero / loop tail>,"w_est":165}],"avoid":[{"name":"footage","rect":[0,280,720,690]},{"name":"subs","rect":[0,685,720,830]}]}`.
  - It goes BELOW the Thai subs (subs y≈707–830), clear of the footage window, the right-rail icons (x≥640) and the bottom-left caption.
  - **`w_est` ต้องคำนวณจากสัดส่วนปกจริง (`w = h × w0/h0` จากขนาด crop); `x`/`y` ใน gfx.json คือจุดกลางของ sticker — rect ที่ layout check ของ `graphics_layer` ตรวจคือ `x ± (w_est+42)/2`, `y ± (h+42)/2`** (บวก 42 = กรอบ+เงา): ขอบขวา `x + (w_est+42)/2 ≤ 640` (x520/h220/w165 → 623 ผ่าน; ปกสูงแคบ 433×726 → h220/w131 → 606 ผ่าน; ปกแนวกว้าง 1.9:1 ที่ h220 → w418 → 750 ล้น ต้องลด h หรือเลื่อน x ซ้าย), ไม่ชนซับ `y − (h+42)/2 ≥ 830` (h=230 → y ≥ 966). **`avoid` ต้องใส่ซับด้วย** (`{"name":"subs","rect":[0,685,720,830]}`): โหมด gameplay ไม่ได้ส่ง `--report` → ระบบตรวจเวลาซับ/ป้ายถูกข้าม เหลือ rect นิ่งใน plan เท่านั้น; ขาดตัวนี้ sticker ที่ตำแหน่ง "ดูต่ำกว่าซับ" ทับซับได้เงียบ ๆ (ข้อความ `image sticker … covers avoid-zone 'subs'` exit 2 = plan ผิด ไม่ใช่ crash)
  - Never put it on full-bleed hero / cold-open shots. **The sticker is one `image_stickers` entry per span BETWEEN hero segs** (e.g. one entry 2.2→8.9 s and another 11.1→14.6 s when a hero seg sits at 9–11 s) — a single start/end that spans a hero shows the sticker over full-bleed picture.
  - **The borrowed end card is full-bleed too**: end the span at that seg's `t0` (printed by `build_v5 --check`), never at `DUR − loop_tail` — the end card carries the real logos, the copyright line and the CTA sub.
  - Re-run verify-clip after (graphics_layer re-encodes FB-safe + a −4 dB limiter). **It also re-encodes the audio through `alimiter=limit=0.5`**, so the `max < −3 dB` gate must be re-measured on `final.mp4` — verify-clip checks duration/profile only, not the peak. **If that peak comes back ≥ −3 dB (a −5.0 dB master has measured −2.4 after graphics added SFX), fix it without rebuilding**: audio-only pass `ffmpeg -y -i final.mp4 -c:v copy -af "alimiter=limit=0.5:level=0" -c:a aac -b:a 128k -ar 48000 -ac 2 -movflags +faststart t.mp4` → re-measure with `volumedetect` (no `-v error`) and re-run verify-clip. Video is bit-untouched and mean loudness stays (limiter pulls peaks only: −2.4 → −4.7 dB with mean unchanged). Do not re-run master.sh or graphics_layer for this — both re-render video.
  - **ยืนยันว่า sticker ขึ้นจริงด้วย pixel diff ไม่ใช่ vision**: เทียบเฟรม **เวลาเดียวกัน** ของ `out.mp4` (ก่อน graphics) กับ `final.mp4` (หลัง) — ทุกค่าต้องเป็น out-vs-final ที่ timestamp เดียวกัน (คนละเวลาคนละคอนเทนต์ เทียบกันไม่ได้) — วัด 3 ค่า: inside-rect ช่วง sticker ขึ้น (ต้องสูง ~15–45), นอก-rect, และ rect เดียวกันแต่นอก-เวลา. สองค่าหลังเป็น baseline ของ re-encode noise — ต้องใกล้กันและ**ห้ามตัดสินด้วยค่าสัมบูรณ์ 0–2** (ขึ้นกับคอนเทนต์ บางคลิปได้ 3–5); baseline สองตัวที่ตรงกันยืนยันพร้อมกันทั้ง "ขึ้นแน่นอน" และ "ไม่ล้นไปโผล่นอก span". **ค่า "นอกเวลา" ต้องรวมเฟรมภายในช่วง full-bleed ที่ sticker ต้องไม่ครอบ (end card / hero) ด้วย** — เช็คแค่ก่อน `start`/หลัง `end` จะผ่านเงียบ ๆ ทั้งที่ sticker ทับการ์ดท้ายอยู่จริง; vision อ่านเฟรมหลัง graphics คืนคำตอบที่ไม่น่าเชื่อถือ
- **cover_crop.jpg** = the CASE FRONT cropped tight out of Fix's ad image. Check completeness by aspect against THAT case type: Switch/Switch 2 ≈1.6 h:w (368×599), PS5 ≈1.37 (529×725); a crop noticeably shorter than its own case type's ratio has clipped the case edge. Get the bbox from the gridded image via vision, then confirm the aspect before use. **Get the bbox from a labelled grid, not from a free-eye estimate:** draw 50-px grid lines with PIL over the image, read the edges off the labels, then crop INSIDE the case edge. Free-eye estimates were 10–20 px off and let a corner badge (中文 彩盒) into the crop. **A grid-vision read returns the ARTWORK bbox, not the whole case** — it drops the platform header strip and the plastic border — so after the grid read, measure the case edges programmatically: walk a pixel column/row through the case centre (PIL, flag steps with total RGB diff > 60) to find plastic edge, header start and artwork end, and crop from those numbers; a case at a slight angle slopes its bottom edge, so take the MAXIMUM bottom across columns or the corner gets clipped. Then vision-check the crop for: corner badges at the top-right of the art, a clipped title letter (widen the crop, don't accept it), and a red case-border strip (harmless, but name it). No price, QR or shop logo, and not the neighbouring case. When the ad has none, use the publisher's box art — **source it from the game's own official site, not from retailers**: grep the site HTML for `package|box|product` image paths (the Muramasa site exposed `…/top_product_package-nsw2-standard.png`, 494×800 RGBA, h:w 1.62 = a full case front with alpha). Amazon / BestBuy / GameStop / MobyGames / GameFAQs / play-asia all block a plain `curl` — don't spend turns there. **Verify by OCR, not by a vision description — publisher art AND listing crops**: vision read a correctly-downloaded cover as a completely different game title (and misidentifies listing boxes just as readily), so run RapidOCR on the crop to confirm title/region (platform header + local title + rating badge), and crop out any QR code and regional rating/language badges the official package art carries (they fail the "no QR" rule even on publisher art). Upscale the crop 2× (LANCZOS) before use so the sticker and thumbnail aren't soft.
  - **QR / ป้าย rating อยู่ในแถบขาว regulation ด้านล่างของปก (ปก JP: CERO + ข้อความ + QR) → กลบเนื้อหาแถบนั้นด้วยสีขาวของแถบเอง ห้ามครอปทิ้ง**: ตัดแถบออก = ตัดขอบ case เสียสัดส่วน ~1.6 แล้วโดน whole-case gate (ต่างจาก QR ที่อยู่บน artwork — อันนั้นครอปเอาออกตามปกติ). **หาแถบด้วย run ของแถวที่ขาวเกิน 90% ต่อเนื่อง — ห้ามสแกนจากล่างแล้วหยุดที่แถวแรกที่ไม่ขาว**: ขอบล่างของ crop มักเป็นแถบสี (ขอบ case) อยู่ใต้แถบขาว → เงื่อนไขนั้นเจอขอบ case ทันทีแล้ว mask เป็น no-op เงียบ ๆ ไม่มี error. เสร็จแล้ว OCR ยืนยันว่าเหลือแค่ชื่อเกม/โลโก้ — ตรวจด้วย OCR ไม่ใช่ vision
  - **The sticker must show the WHOLE case front — never a partial crop.** When a promo panel/banner covers part of the case in the ad, cropping the clean region yields half a cover, and Fix rejects it. Gate by aspect ratio before use: a Switch/Switch 2 case front is ~1.6 h:w (368×599 measured), a PS5 front ≈1.37 (529×725 measured); a crop near 1.0 or below (e.g. 440×387) means the case was cut. Then get a full cover: publisher/Nintendo store box art, or ask Fix once for a clean cover image (he supplies one quickly). Do not ship a half cover "for now".
  - Tested on the Yu-Gi-Oh clip: `ygo_cover_sticker_demo.mp4` (sent to Fix, msg 7137), cover at x433–605 / y836–1083, nothing covered.
- **Thumbnail — SUPERSEDED 2026-11-17: build the poster cover (`/opt/data/skills/shopee-clip/references/poster-cover.md`; the case front is one of its circles). The `make_cover.py` recipe below is kept as history and for picking a clean frame time (`--t` gap rules still apply to the hero frame).** Old recipe: run `uv run --with pillow --with numpy python /opt/data/skills/shopee-clip/scripts/make_cover.py --video out.mp4 --t <gap> --text "<≤3 คำ EN>" --out thumb_base.jpg` (`--video` กับ `--out` เป็น required — ไม่ใส่ = usage error; pre-sub source; numpy is required, pillow-only fails), then `send_photo.py`. **`--t` must land in a gap free of EVERY burned layer** — after a sub ends and before the next starts AND outside every pill span, read both from `work/timeline_v5.json`: build_v5 leaves no pre-sub concat, subs can cover nearly the whole clip, and make_cover's default `--range` (5–80%) only skips the CTA tail, so auto-picking returns a frame with a caption or a pill on it. **The `image_stickers` span in gfx.json counts as a burned layer too**: a frame inside the span already shows the case, and compositing the card over it doubles the cover — when the sticker spans nearly the whole clip, shorten its `end` to before the chosen `--t` and re-run `graphics_layer` (cheap) instead of hunting for a frame. Pick `--t` from a moment after the last burned-in caption has ended, and read the `main_box` the script prints: place the cover composite outside that box (below it, bottom-right, x = W − w − 90, y = H − h − 250 — the sizing rule below derives h so this clears `main_box.bottom`) so it neither hides the title nor the caption; a thumbnail whose cover overlaps the title or a caption fails vision check. **Fix 2026-11-08: the thumbnail MUST also carry a crop of the product / game cover** (product clip → product crop; gameplay clip → game case cover crop from the listing image, same bbox rule as the sticker). make_cover alone is not enough: composite the cover crop onto the thumbnail (white border, bottom-right inside the safe zone) before sending. **ตั้งขนาดตามขอบที่ชนจริง — สอง constraint พร้อมกัน: `w ≤ ~620 px` (canvas 1080) ไม่ให้ล้นขอบซ้าย และ `y = H − h − 250 ≥ main_box.bottom` ไม่ให้ทับ title.** crop สินค้าสัดส่วน ~1.9:1 (แนวกว้าง) โดน constraint ความกว้าง → ตั้ง `w ≤ 620` แล้วคูณสัดส่วน (ตั้ง `h=520` จะกว้าง ~980 px แล้วล้นขอบซ้ายออกนอกเฟรม); **ปกเกม/กล่องสินค้าแนวตั้ง (h:w ~1.6) โดน constraint ความสูง** → คำนวณ `h` จาก `y = H − h − 250 ≥ main_box.bottom` ก่อน (canvas 1920, title ล่างที่ 1009 → h ≤ 661) แล้วค่อย `w = h × w0/h0` — ตั้งจากความกว้างกับปกสูง = การ์ดยาวขึ้นไปทับ title ทันที. วาง `x = W − w − 90`, `y = H − h − 250` แล้ว vision เช็คว่าไม่ชนข้อความปก. **เช็ค `main WxH` ที่ make_cover พิมพ์ด้วย**: `main` กว้างกว่า ~1000 px หรือ `main_box` ขวาเกิน canvas = โดนตัดแม้ `--text` จะ ≤3 คำ (`MURAMASA REVENANT BLADES` ล้นจริง) → สั้นคำให้ `main` ≤ ~1000 px แล้วรันใหม่ (คำเดียวหรือสองคำสั้นก็ได้ เช่น `MONSTER HUNTER` = 690 px ผ่าน).
