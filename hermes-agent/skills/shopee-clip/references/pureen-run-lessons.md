# Lessons from the 2026-11-08 Pureen run (narrow layout, two-scene presenter clip)
- **Graphics v2 is required before any final send.** Fix flagged a plain post_presenter build with no product cutout and no stickers as a miss. Run `presenter_fx.py` (overlay cutout beside the presenter, punch-in) on the raw scenes, then `post_presenter.py`, then `graphics_layer.py --check` and render, and only then send. Overlay coordinates that fit Flow's pink backdrop: x≈655, y≈330, h≈120-130. `layout_probe.py` is conservative and reports 'no empty side' on these scenes; trust one vision read of the frame over it.
- **Short cutout durations are invisible.** A 1.2 s hook card and a 1.0 s insert were barely visible in the contact sheet; 3.0 s and 3.2 s read clearly. Use 3 s or more.
- **Subtitle drop fix:** `post_presenter` SKIPPED a phrase whose words were separated by a space inside the script (`ไม่แสบตา อ่อนโยน`). Writing it without the internal space (`ไม่แสบตาอ่อนโยน`) got it burned.
- **Narrow layout (w≈800):** the add-ingredients button sits near (127,408). The picker lists only some characters; scroll the overlay to reveal more. Read the chip `img` alt/src after each attach and confirm the character before submitting.
- **After Start generation the prompt clears, but the clip may not appear for minutes.** Wait about 5 min, then `Page.reload`. The new tile shows at the top of the grid. Do not resubmit before that, because each resubmit can spend credits.
- **Download in the narrow editor:** click More options (~670,29), then Download media (~587,163), then 720p Original size (~415,237), all via `click_at_xy`. browser_exec loses Python variables between calls, so locate the file in the terminal with `find /opt/data/Downloads /opt/data/home/Downloads -name '*.mp4' -mmin -8`.
- **Long renders:** a foreground call over 600 s is auto-promoted to background. `presenter_fx` on one scene took about 4 min.
- **Terminal cwd trap:** if the persisted cwd points at a deleted directory, every terminal call fails with exit 126. Pass `workdir=` explicitly.
