1

เตรียมข้อมูลสินค้าและรูปจริง

ทำใน Shop · เป้าหมาย: ระบบมีข้อมูลที่นำไปพูดได้ และมีรูปที่ใช้ยึดรูปลักษณ์สินค้า

  1. เปิด Creator Studio → Shop แล้วสร้างสินค้าใหม่
  2. เลือกปลายทาง Shopee Video, Facebook หรือ YouTube ให้ตรงกับที่คุณจะโพสต์
  3. ใส่ชื่อ รายละเอียดที่ยืนยันได้ ราคาและราคาเดิมเมื่อมีข้อมูลจริง รวมถึงลิงก์ affiliate ถ้าจะใช้
  4. อัปโหลดรูปสินค้าจริง 1–6 รูป แล้วรอการตรวจไฟล์ให้ผ่านก่อนสร้างแผน
ข้อมูลน้อยก็พูดให้น้อยอย่าเติมความจุ วัสดุ ยอดขาย รีวิว หรือสรรพคุณจากการเดา โมเดลใช้ข้อความที่คุณให้เขียนบท ไม่ได้ตรวจรายละเอียดในรูปแทนคุณ
ตัวอย่างที่เราจะใช้ตลอดคู่มือ

มีข้อมูล: รูปร่างมีหูจับ สีครีม และราคา 129 บาท ซึ่งผู้ใช้ระบุเอง
ยังไม่มีข้อมูล: วัสดุ ความจุ การเข้าไมโครเวฟ และการเก็บอุณหภูมิ จึงไม่ใช้เป็นคำขายหรือการสาธิต

2

ตรวจบท เลือกรูป และยืนยันแผนฉาก

ทำใน Shop · เป้าหมาย: ทุกฉากพูดข้อเท็จจริงเดียวกับที่คุณให้ และเลือกรูปอ้างอิงถูกภาพ

  1. กด สร้างแผนฉาก ระบบเตรียมบท 3–6 ฉาก พร้อมเสียงพากย์ ข้อความบนจอ และคำสั่งสร้างภาพเคลื่อนไหว
  2. อ่านทั้งบทพากย์ คำอ่าน ซับ ราคา caption และคำชวนดูสินค้า โดยเฉพาะตัวเลขและข้อกล่าวอ้าง
  3. ตรวจรูปอ้างอิงของแต่ละฉาก เลือกแหล่งภาพเป็น Flow / วิดีโอถ่ายจริง / ภาพนิ่ง ให้ตรงกับไฟล์ที่จะใช้ ต้องมีวิดีโออย่างน้อยหนึ่งฉาก
  4. ถ้าแก้บท ให้บันทึกและรอตรวจแผนอีกครั้ง จากนั้นยืนยันข้อเท็จจริงและกด ยืนยันแผนฉาก

3

นำรูปและ prompt ไปสร้างใน Google Flow

ทำด้วยตัวเองในบัญชี Flow · เป้าหมาย: ได้ไฟล์วิดีโอที่สินค้าตรงรูปอ้างอิง

  1. เปิด Google Flow และเลือกวิธีสร้างวิดีโอที่รองรับรูปอ้างอิงตามตัวเลือกที่มีในบัญชีของคุณ
  2. เพิ่มรูปอ้างอิงของฉากจาก Shop แล้ววาง prompt ของฉากเดียวกัน
  3. เลือกภาพแนวตั้งเมื่อมีตัวเลือก และสร้างวิดีโอโดยคงตัวสินค้า สี รูปทรง และฉลากให้ตรงรูป
  4. ดูผลลัพธ์ทั้งฉาก หากสินค้าผิดรูปหรือแปรสภาพ ให้แก้คำสั่งและสร้างใหม่ หรือใช้วิดีโอถ่ายจริง
  5. ส่งออก/ดาวน์โหลดวิดีโอ ตั้งชื่อแยกง่าย เช่น scene-01.mp4 แล้วทำฉากถัดไป

ตัวเลือก ชื่อปุ่ม และความสามารถใน Flow อาจต่างกันตามบัญชีและเวอร์ชัน คู่มือนี้จึงอธิบายเป็นขั้นตอนทั่วไป ไม่ระบุปุ่มที่ต้องมีเหมือนกันทุกบัญชี

ตัวอย่าง prompt แบบย่อ · ใช้ prompt จริงของฉากเป็นหลัก
Create a vertical product shot using the supplied reference. Keep the cream mug's shape, handle, colour and existing markings unchanged. Use a static camera and a slow neutral turntable rotation. Do not invent material, capacity or heat-retention demonstrations. Do not add text, logos, subtitles, prices or audio.
ความยาววิดีโอต้องพอกับเสียงพากย์Shop วัดเวลาจริงเมื่อสร้างเสียง หากวิดีโอสั้นกว่าช่วงพากย์ ระบบจะระบุฉากและเวลาที่ขาด คุณต้องย่อบทหรือส่งออกคลิปที่ยาวขึ้น ระบบไม่วนวิดีโอหรือแช่เฟรมท้ายเพื่อเติมเวลา
4

อัปโหลดกลับให้ตรงฉาก แล้วตรวจรับทีละฉาก

กลับมาที่ Shop · เป้าหมาย: ทุกฉากมีไฟล์ที่ผ่านการตรวจ และคุณยอมรับว่าตรงสินค้า

  1. เปิดฉากที่ตรงกับไฟล์ เลือกอัปโหลด MP4/MOV สำหรับฉาก Flow หรือวิดีโอถ่ายจริง หากเป็นภาพนิ่งให้ใช้ไฟล์รูป
  2. รอการตรวจไฟล์ หากไม่ผ่าน ให้อ่านสาเหตุและเปลี่ยนไฟล์ก่อนดำเนินต่อ
  3. ดูตัวอย่างภาพจนจบ เลือก Crop หรือ Contain ตามพื้นที่ที่ต้องรักษา
  4. หากแก้ Crop/Contain แหล่งภาพ หรือรูปอ้างอิง: ปรับให้ครบทุกฉากก่อน แล้วกด บันทึกบทและฉาก รอระบบตรวจแผน ตรวจและกด ยืนยันแผนฉาก อีกครั้ง การแก้แผนจะล้างการยอมรับฉากเดิม จึงต้องตรวจและยอมรับทุกฉากใหม่หลังยืนยันแผน
  5. เทียบกับรูปอ้างอิงอีกครั้ง ดูหูจับ ขอบ รูปทรง สีและฉลาก รวมถึงวัตถุที่โผล่มาหรือหายไป
  6. ยืนยันว่าตรงรูปอ้างอิง แล้ว ยอมรับฉาก ทำให้ครบทุกฉากก่อนสั่งตัดต่อ
ตรวจไฟล์ผ่าน ≠ สินค้าตรงรูปแล้วการตรวจอัตโนมัติยืนยันว่าไฟล์อ่านได้และอยู่ในข้อจำกัด คุณยังต้องตรวจความถูกต้องของสินค้าเอง เสียงต้นฉบับของวิดีโอจะถูกตัดออกตอนประกอบคลิป
5

สั่งตัดต่อ แล้วให้ n8n ประสานงาน

เริ่มที่ Shop · เป้าหมาย: ได้คลิปที่ประกอบจากชุดบทและฉากที่ยืนยันแล้ว

  1. ตรวจว่าทุกฉากยอมรับแล้ว ไม่มีไฟล์ใหม่ที่ยังรอตรวจ และมีวิดีโออย่างน้อยหนึ่งฉาก
  2. กด ตัดต่อคลิป งานจะเข้าสู่สถานะรอเริ่ม n8n ที่เปิดใช้งานไว้จะส่งต่อให้ worker เริ่มตัดต่อ
  3. Shop สร้างเสียงพากย์ไทย วัดเวลา จัดภาพแต่ละฉาก วางข้อความและการ์ดท้าย จากนั้นประกอบคลิป
  4. ติดตามสถานะใน Shop และข้อความแจ้งเตือน Telegram เมื่อเปิดใช้การแจ้งเตือนไว้ งานหนึ่งอาจรอคิวหากมีงานอื่นกำลังตัดต่อ
สถานะตัดต่อภาพหน้าจอจำลอง ไม่ใช่ screenshot
รอ n8n เริ่มงานเข้าคิวกำลังตัดต่อพร้อมตรวจ

ภาพนี้สรุปลำดับสถานะ ไม่ใช่เวลาที่รับประกัน และการกดซ้ำไม่ได้ทำให้งานเดิมเร็วขึ้น

งานตัดต่อใช้ชุดข้อมูลที่ตรึงไว้ตอนสั่งงานหากคุณแก้สินค้า บท หรือสื่อภายหลัง ให้ตรวจสถานะเวอร์ชันก่อนอนุมัติคลิปเก่า การแก้ไขอาจต้องยืนยันแผนหรือฉากใหม่ แล้วสั่งตัดต่อเวอร์ชันปัจจุบัน
6

ตรวจคลิป ยืนยัน แล้วดาวน์โหลดไปโพสต์เอง

ทำใน Shop และแพลตฟอร์มปลายทาง · เป้าหมาย: โพสต์คลิปเวอร์ชันที่คุณตรวจครบแล้ว

  1. ดูคลิปตั้งแต่ต้นจนจบ พร้อมเปิดเสียง ฟังคำอ่านภาษาไทยและจังหวะเปลี่ยนฉาก
  2. ตรวจซับไม่ล้นจอ สินค้าไม่ถูกตัดส่วนสำคัญ ราคาและคำชวนดูสินค้าตรงกับปลายทาง
  3. หากถูกต้อง ให้ยืนยันคลิปสุดท้ายของเวอร์ชันปัจจุบัน แล้วดาวน์โหลด MP4 และไฟล์ caption
  4. เปิดแพลตฟอร์มที่เลือกและโพสต์ด้วยตัวเอง ตรวจลิงก์/ตำแหน่งลิงก์ให้ใช้งานได้จริงก่อนเผยแพร่

รายการข้อกำหนด
รูปอ้างอิง1–6 รูปต่อสินค้า · JPEG / PNG / WebP · ไม่เกิน 15 MiB ต่อไฟล์ · ภาพนิ่งเท่านั้น
ขนาดรูปกว้างและสูงอย่างน้อย 64 px · ไม่เกิน 8,192 px ต่อด้าน และไม่เกิน 40 ล้านพิกเซลรวม
แผนฉาก3–6 ฉาก · มีวิดีโอจาก Flow หรือวิดีโอถ่ายจริงอย่างน้อย 1 ฉาก · ทุกฉากต้องมีรูปอ้างอิงและผ่านการยืนยันก่อนตัดต่อ
วิดีโออัปโหลดMP4 / MOV · ไม่เกิน 100 MiB ต่อไฟล์ · ความยาว 0.1–60 วินาที · 1–60 fps · ไฟล์และ codec ต้องผ่านการตรวจอ่านจริง
ขนาดวิดีโอไม่เกิน 3,840 × 2,160 px หรือสลับเป็นแนวตั้ง 2,160 × 3,840 px · ด้านสั้นไม่เกิน 2,160 px · แต่ละด้านอย่างน้อย 64 px
ความยาวคลิปเสียงพากย์จริงรวมช่วงท้ายต้องไม่เกิน 60 วินาที วิดีโอต้องยาวพอกับช่วงพากย์ของแต่ละฉาก ระบบตัดคลิปที่ยาวกว่าให้พอดี แต่ไม่วนหรือแช่ภาพเพื่อยืดวิดีโอ
คลิปที่ได้แนวตั้ง 1,080 × 1,920 px · เสียงพากย์ไทย ข้อความบนภาพและการ์ดท้าย · ไม่ใช้เสียงต้นฉบับจากวิดีโอที่อัปโหลด
การเผยแพร่ตรวจและยืนยันคลิปใน Shop จากนั้นดาวน์โหลดไปโพสต์เอง ไม่มีการสร้างฉาก Flow หรือเผยแพร่บนแพลตฟอร์มแทนคุณในเส้นทางนี้

MiB เป็นหน่วยขนาดไฟล์ที่ระบบใช้ บางแอปแสดงขนาดเป็น MB ต่างกันเล็กน้อย หากไฟล์ใกล้เพดาน ให้ส่งออกให้เล็กลงอีกเล็กน้อย

ติดตรงไหน ให้กลับไปแก้ตรงนั้น

อ่านสาเหตุใน Shop ก่อน การสั่งตัดต่อใหม่ไม่ช่วยแก้ไฟล์ที่ยังผิดหรือฉากที่ยังไม่ยอมรับ

สร้างแผนไม่สำเร็จ

ตรวจรายละเอียดสินค้าและรูปที่ผ่านการตรวจ แล้วลองสร้างใหม่ ระบบแยกข้อผิดพลาดการสร้างบทจากแผนเดิมที่เคยใช้ได้

บทหรือคำชวนซื้อไม่ผ่าน

ตรวจตัวเลข คำอ่าน ซับที่ต้องตรงกับบท และคำปิดให้ตรงปลายทาง แก้แล้วบันทึก รอผลตรวจแผนก่อนยืนยันอีกครั้ง

Flow ทำสินค้าเปลี่ยนรูป

อย่ายอมรับฉากนั้น เทียบรูปอ้างอิงแล้วสร้างใหม่ ลดคำสั่งที่ซับซ้อน หรือเปลี่ยนฉากไปใช้วิดีโอถ่ายจริงที่ตรงสินค้า

อัปโหลดไฟล์ไม่ผ่าน

ตรวจชนิด ขนาด ความยาวและมิติไฟล์ หากเปลี่ยนไฟล์ฉากแล้วไฟล์ใหม่เสีย ระบบจะคงไฟล์เดิมที่ผ่านไว้ ให้ตรวจว่าภาพที่เห็นเป็นไฟล์ใดก่อนยอมรับ

วิดีโอสั้นกว่าเสียงพากย์

ดูหมายเลขฉากและเวลาที่ต้องการในข้อผิดพลาด ย่อบทแล้วตรวจ/ยืนยันแผนและฉากใหม่ หรือส่งออกวิดีโอฉากเดิมให้ยาวขึ้น จากนั้นลองตัดต่อใหม่

ค้างที่รอเริ่มตัดต่อ

ให้ผู้ดูแลตรวจ n8n และ worker ตามคู่มือติดตั้ง หากมีงานอื่นตัดต่ออยู่ให้รอคิว หน้า Shop เป็นจุดติดตามสถานะ ไม่ต้องอัปโหลดฉากซ้ำเพราะรอคิว

คลิปพร้อม แต่ Telegram ไม่แจ้ง

เปิดดูสถานะและคลิปใน Shop ได้ ข้อผิดพลาดการแจ้งเตือนไม่ทำให้คลิปที่ตัดต่อสำเร็จกลายเป็นงานเสีย ใช้คำสั่งลองแจ้งเตือนใหม่เมื่อจำเป็น

หน้าแจ้งข้อมูลเปลี่ยน / คลิปเก่าแล้ว

เก็บข้อความที่ยังแก้ค้างก่อนโหลดข้อมูลล่าสุด ตรวจเวอร์ชันและยืนยันใหม่ตามที่ระบบแจ้ง คลิปเก่าอาจดาวน์โหลดได้ แต่ใช้ยืนยันแทนงานเวอร์ชันปัจจุบันไม่ได้

แก้แล้วตรวจสถานะก่อนเริ่มรอบใหม่หากงานตัดต่อเดิมล้มเหลว ให้ใช้การลองตัดต่อใหม่หลังแก้สาเหตุ สำหรับการเปลี่ยนบทหรือสื่อ ให้ตรวจแผนและการยอมรับฉากของเวอร์ชันปัจจุบันอีกครั้ง

เช็กครบก่อนถือว่าพร้อมโพสต์

ช่องเช็กนี้ใช้ช่วยอ่านคู่มือหรือพิมพ์ตรวจงาน ไม่ได้ส่งผลไปเปลี่ยนสถานะใน Shop และไม่ได้บันทึกข้ามการเปิดไฟล์
