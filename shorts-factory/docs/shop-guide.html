1. เตรียมของในแอป Shopee

  • ลิงก์ affiliate — กดแชร์จากหน้าสินค้าในแอป Shopee (ขณะล็อกอินบัญชี affiliate) แล้วคัดลอกลิงก์
  • รูปสินค้า 1–6 รูป — เซฟจากหน้าสินค้า เลือกรูปที่ชัด พื้นเรียบ เห็นตัวสินค้า รูปแรกจะถูกใช้ในการ์ดท้าย จึงควรเป็นรูปที่สวยที่สุด
  • ข้อความ — ชื่อสินค้า ราคาขาย ราคาก่อนลด และรายละเอียด/สเปกที่ก๊อปจากหน้าสินค้า
ยิ่งให้ข้อมูลเยอะ สคริปต์ยิ่งมีเนื้อหา บอทพูดได้เฉพาะสิ่งที่อยู่ในข้อความที่ส่งไป ไม่ได้ค้นเว็บและไม่แต่งเพิ่ม ถ้าส่งแค่ชื่อกับราคา คลิปจะไม่มีอะไรให้พูดถึง

2. ขั้นตอนในบอท

  1. พิมพ์ /shop

    บอทต้องว่างอยู่ ถ้ามีสคริปต์ค้างรีวิวหรือกำลัง render อยู่ ให้ทำอันนั้นให้เสร็จก่อน จะพิมพ์ข้อความต่อท้ายไปเลยก็ได้ เช่น /shop ราคา 299 …

  2. ส่งรูปและข้อความ

    ส่งรูปเป็นอัลบั้มทีเดียวได้ ข้อความจะส่งหลายครั้งก็ได้ บอทต่อให้เอง ทุกครั้งที่ส่ง บอทจะตอบสถานะกลับมา:

    📷 📷 📷 (3 รูป)
    หูฟังบลูทูธ TWS Pro 5.3 ราคา ฿299 จากปกติ ฿499 แบตใช้ได้ 6 ชม. รวมกล่อง 30 ชม. กันน้ำ IPX5 ชาร์จ USB-C https://s.shopee.co.th/…
    🛍 รูป 3/6 · ข้อความ ✔ · ลิงก์ ✔ ส่งรูปเพิ่ม หรือพิมพ์รายละเอียดเพิ่มได้ ครบแล้วกด ✅
    ✅ ครบแล้ว เขียนสคริปต์🗑 ยกเลิก
    • ส่งเป็นรูปธรรมดา ถ้าส่งเป็นไฟล์ รับเฉพาะ JPG / PNG / WEBP (ไฟล์ HEIC จาก iPhone ใช้ไม่ได้)
    • แต่ละรูปต้องไม่เกิน 20MB
    • รูปถูกนับเลข 1, 2, 3… ตามลำดับที่ส่ง เลขนี้จะโผล่ในสคริปต์ว่าฉากไหนใช้รูปไหน

  3. กด ✅ แล้วรอประมาณ 1 นาที

    บอทเขียนสคริปต์ (Pitch) แล้วส่งมาให้อ่าน หลังกด ✅ แล้วจะเพิ่มรูปไม่ได้ ถ้าอยากเปลี่ยนรูป ต้องกด 🗑 แล้วเริ่ม /shop ใหม่

  4. รีวิว — พิมพ์แก้ แล้วเลือก 🎬 หรือ 🎞

    พิมพ์บอกได้เลยว่าอยากแก้ตรงไหน เช่น "hook เปิดด้วยเรื่องออกกำลังกาย" บอทจะเขียนใหม่ทั้งชุด ถ้าลืมใส่ลิงก์ พิมพ์ลิงก์ตอนนี้ได้ บอทจะเอาไปใส่ใน caption ให้ พอใจแล้วเลือกวิธีทำคลิป:

    🛍 หูฟังบลูทูธ 5.3 แบตอึด …
    🎞 Studio (Flow + ตัวละครพูด)
    🎬 render (รูปสินค้า)🗑 ทิ้ง
    • 🎬 render (รูปสินค้า) — แบบเดิม: รูปสินค้าจริงขยับช้าๆ + เสียงพากย์ผู้หญิง + การ์ดราคาท้ายคลิป ได้คลิปใน ~2 นาที (ข้อ 5 ด้านล่าง)
    • 🎞 Studio — ทำภาพใน Google Flow ทุก shot ตัวละครถือสินค้าแล้วพูดเอง ไม่มีการ์ดราคา (ดู หัวข้อ 🎞 Studio)

  5. ได้คลิปกลับมา (ประมาณ 2 นาที)

    บอทส่งมา 3 อย่าง: ไฟล์ mp4, caption พร้อมโพสต์ (กดค้างแล้วก๊อป) และ Sub ID ที่แนะนำให้ใช้ ไฟล์ทั้งหมดเก็บไว้บน NAS ด้วย

    หูฟังบลูทูธ 5.3 แบตอึด กันน้ำ IPX5 ราคา 299 บาท หูฟังบลูทูธไร้สาย … ตอนนี้ราคาพิเศษ 299 บาทค่ะ 🛒 https://s.shopee.co.th/… #ad มีลิงก์ affiliate — ซื้อผ่านลิงก์นี้ คนทำคลิปได้ค่าคอมเล็กน้อย ราคาเท่าเดิม #หูฟังบลูทูธ #หูฟังไร้สาย …

🎞 Studio: ทำใน Flow ตัวละครพูดเอง

ใช้ flow เดียวกับ 🎞 Studio pack ของคลิป Shorts (ดู คู่มือ Studio Pack) แต่ล็อกไว้ 3 อย่าง: ภาพ Flow ทุก shot (ไม่มี Pexels/รูปนิ่ง), ตัวละครพูดเองเสมอ และ ไม่มีการ์ดราคา — ประโยคปิด ("กดตะกร้า…") เป็น shot สุดท้ายที่ตัวละครพูด

  1. ตั้งตัวละครครั้งแรก

    dashboard → ตั้งค่า → การ์ด ค่าเริ่มต้นของ Studio pack 🎞 → ตัวละครคลิปสินค้า 🛍 เลือกคนจากคลัง หรือ 🤖 ให้บอทแต่ง (บอทบังคับเป็นผู้หญิง เพราะบทลงท้าย ค่ะ) เปลี่ยนทีหลังได้ด้วยปุ่มบน pack

  2. กด 🎞 Studio ตอนรีวิว (~2-5 นาที)

    บอทอัดเสียงวัดความยาวทุกประโยค ประโยคที่ยาวเกินพูดทันใน 10 วิ บอทย่อให้เอง (ตัวเลขยังเป็นตัวเลขจากข้อความที่ส่ง ซับเปลี่ยนตาม) แล้ววางฉาก 1 ประโยค = 1 shot ส่ง script.md + ข้อความ pack + ลิงก์หน้า pack บอทว่างทันที ทำคลิปอื่นต่อได้ pack รอได้ 72 ชม.

    🎞 Studio pack v1 — หูฟังบลูทูธ 5.3 แบตอึด 🗣 ตัวละครพูดเอง · การ์ด Flow: 1, 2, 3, 4, 5 · 5 shot = 40 วิ ≈ 60+ เครดิต ทุก shot 8 วิ หน้า copy + อัปไฟล์: https://…/storyboard/p2610… 🛍 สร้าง Asset Profile @Product จากรูปสินค้าในหน้าเว็บ · ทุก shot แนบตัวละคร + สินค้า · export ต้องมีเสียง
    @Kim ✓🤖 แต่งใหม่
    ↩️ กลับไปรีวิว Pitch🗑 เลิกทำคลิปนี้

  3. ทำใน Google Flow

    • เปิดหน้า pack → การ์ด 🛍 สินค้า @Product → โหลดรูปสินค้า → ใน Flow สร้าง Asset Profile ชื่อ @Product จากรูป (เหมือนสร้างตัวละคร)
    • วาง script.md ใน Storyboard Studio (มีบรรทัด Products: บอกว่า @Product คืออะไร และห้ามเปลี่ยนรูปทรง/สี/ฉลาก)
    • Animate ทีละ shot: แนบ ตัวละคร + @Product + frame ตั้งความยาวตามป้าย ตั้ง 8s/10s ของแต่ละ shot แล้ววาง prompt Speaks in Thai: "…"
    • เช็คทุก shot ว่า สินค้าไม่เพี้ยน (รูปทรง สี ตัวหนังสือบนกล่อง โลโก้) และพูดราคาถูก ถ้าเพี้ยนให้เจน shot นั้นใหม่
    • Scenes เรียงตามลำดับ → export มีเสียง ไฟล์เดียว

  4. ส่งไฟล์กลับ → ได้คลิป + caption

    reply ไฟล์ที่ข้อความ pack (≤20 MB) หรืออัปที่หน้า pack (≤100 MB) บอทหั่นตาม shot แล้ว render: ภาพ Flow + เสียงตัวละครเอง + ป้ายด้านบน + ซับ + เพลง ส่ง mp4 + caption (#ad + ลิงก์) เหมือนแบบ 🎬 ไฟล์เก็บที่ /volume1/shorts/shop/<id>/ แล้ว pack ถูกลบ

    ความยาวไฟล์ไม่ตรง (เช่นตัดท้าย shot เอง) บอทถามก่อนพร้อมปุ่ม ✂️ หั่นเท่าๆ กัน

เปลี่ยนใจได้ ↩️ = Pitch กลับมาให้รีวิว (กด 🎬 แบบรูปสินค้าแทนได้) · 🗑 = ทิ้ง pack · pack ใช้ช่องเดียวกับ Studio pack ของคลิป Shorts — ถ้ามีอีกอันค้าง บอทจะบอกให้ทิ้ง/ส่งไฟล์ของอันนั้นก่อน · เครดิต: shot 8 วิ ≈ 12, 10 วิ ≈ 15
ยังไม่ได้ยืนยันจากของจริง Flow ผูก Asset Profile 2 อัน (ตัวละคร + @Product) ใน scene เดียวได้ไหม · Veo อ่านตัวเลขราคาถูกไหม · ฉลากสินค้าเพี้ยนบ่อยแค่ไหน — คลิปแรกให้ดูละเอียด

อยากทำบนเว็บแทน Telegram: Creator Studio /shop → ตอนสร้างงานเลือก วิธีทำคลิป = 🎞 Studio (ดู คู่มือ Shop Flow Studio)

4. โพสต์ที่ไหน

ที่ลิงก์กดได้ไหมวิธี
Shopee Video (ในแอป Shopee)แท็กสินค้าได้อัปคลิป แล้วแท็กสินค้าตัวเดียวกันในแอป คนดูกดซื้อได้ทันที ครั้งแรกให้เช็คในแอปว่าค่าคอม affiliate นับอย่างไร (ยังไม่ได้ verify)
Facebook Reels / Pageยังไม่ได้ verifyวาง caption แล้วใส่ลิงก์ในคอมเมนต์แรก
YouTube Shortsกดไม่ได้YouTube ปิดลิงก์ใน Shorts มาตั้งแต่ปี 2023 ให้ใส่ลิงก์ไว้ใน About ของช่องแทน เหมาะกับการสร้างยอด subscriber ไปจนถึง YPP แล้วค่อยใช้ Shopping tag
ห้ามลบบรรทัด #ad — เป็นการบอกคนดูว่าในคลิปมีลิงก์ affiliate ทั้งแพลตฟอร์มและ Shopee กำหนดให้เปิดเผยเรื่องนี้ อย่าโพสต์คลิปของ /shop เข้าช่อง YouTube หลัก ให้แยกช่อง เพราะคลิปขายของอาจโดนนโยบาย reused content แล้วลามไปถึงช่องหลัก

5. ทำไมสคริปต์ถึงโดนตีกลับ

บอทตรวจสคริปต์ก่อนส่งมาให้รีวิว ถ้าผิดกติกาจะสั่งให้โมเดลเขียนใหม่เองโดยอัตโนมัติ ถ้าเขียนไม่ผ่านจนหมดเวลา จะแจ้ง "เขียนสคริปต์ไม่สำเร็จ" พร้อมเหตุผล

  • ตัวเลขทุกตัวต้องอยู่ในข้อความที่ส่งไป รวมเลขหลักเดียวด้วย เช่น "5 ดาว" ถ้าข้อความไม่มี = ห้ามพูด ตัวเลขในลิงก์ไม่นับ
  • ห้ามโมเดลเขียน % ส่วนลดคำนวณจากราคาขายและราคาก่อนลดให้เอง
  • ซับต้องตรงกับเสียง คนดูคลิปขายของส่วนใหญ่ปิดเสียง
  • เสียงผู้หญิง ใช้ ค่ะ/คะ ถ้ามีคำว่า "ครับ" จะถูกตีกลับ
  • ห้ามเคลมเกิน เช่น ผลทางการแพทย์ หรือ "ดีที่สุด" ที่ไม่มีอยู่ในข้อความ
ถ้าโดนตีกลับบ่อย ส่วนใหญ่เป็นเพราะข้อความที่ส่งไปมีข้อมูลน้อยเกินไป ให้ก๊อปรายละเอียดจากหน้าสินค้าเพิ่ม แล้วกด ✅ อีกครั้ง

6. แก้ปัญหา

อาการทำยังไง
บอทตอบ "มีคลิปสินค้าเปิดอยู่"พิมพ์ /shop อีกครั้ง บอทจะส่งปุ่มของอันที่ค้างอยู่กลับมา จากนั้นทำต่อ หรือกด 🗑 ทิ้ง
ส่งหัวข้อคลิปปกติไม่ได้ระหว่างที่คลิปสินค้าเปิดอยู่ ข้อความที่พิมพ์จะถือเป็นข้อมูลของสินค้า ให้ทำคลิปสินค้าให้เสร็จหรือกด 🗑 ก่อน
ปุ่มหายหลังบอทรีสตาร์ทบอทส่งปุ่มกลับมาให้เองตอนเริ่มใหม่ ถ้าไม่เห็น พิมพ์ /shop
render ล้มเหลว: No audio was receivedบริการเสียงปัดคำขอเป็นครั้งคราว บอทกลับไปหน้ารีวิวให้แล้ว กด 🎬 อีกครั้ง
"รูปยังโหลดไม่ครบ"รอสักครู่แล้วกด ✅ อีกที
"ไฟล์นี้ใช้ไม่ได้"ส่งเป็นรูปธรรมดาแทนการส่งเป็นไฟล์ หรือแปลงเป็น JPG ก่อน
กด 🎞 แล้วบอกว่า "ยังมี Studio pack ค้างอยู่"มี pack อื่น (Shorts หรือสินค้า) รออยู่ ส่งไฟล์ของอันนั้นหรือกด 🗑 ที่ pack นั้นก่อน Pitch นี้กลับมาให้รีวิวแล้ว
กด ↩️ บน pack สินค้าแล้วไม่กลับบอทต้องว่าง (ไม่มีสคริปต์ค้างรีวิว/คลิปสินค้าอื่นเปิดอยู่) ไม่งั้นได้ปุ่ม 🗑 แทน
ทิ้งไว้นานคลิปสินค้าที่ไม่มีใครกดอะไรนาน 6 ชั่วโมงจะถูกปิดเอง รูปที่ส่งไปยังอยู่บน NAS

ไฟล์อยู่ที่ /volume1/shorts/shop/<id>/ มี <id>.mp4, caption.txt, shop.json (ข้อมูลที่ส่งไป + สคริปต์ + ค่าที่ใช้ render) และโฟลเดอร์ photos/

คลิปสินค้าไม่ถูกนับใน /stats, /experiment และไม่ขึ้นบน dashboard ของคลิปปกติ

7. วัดผลด้วย Sub ID

ลิงก์ที่แชร์จากแอปไม่มี Sub ID ทำให้แยกไม่ได้ว่าคลิปไหนทำเงิน ถ้าอยากรู้:

  1. เปิด affiliate.shopee.co.th → ลิงก์ที่กำหนดเอง
  2. วางลิงก์สินค้า แล้วใส่ Sub ID เป็นเลขที่บอทให้ (เช่น p261013091500)
  3. ใช้ลิงก์นี้แทนลิงก์ใน caption
  4. ดูผลที่ รายงานคลิก / รายงานคำสั่งซื้อ ใน Affiliate Portal หรือนำเข้า CSV ที่หน้า Creator Studio → /shop/revenue ระบบจับคู่ Sub ID กับงานให้ (งานที่ทำบนเว็บมี Sub ID ต่อช่องทางให้แล้ว)
